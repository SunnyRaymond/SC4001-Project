For an image with label $y$, let $\hat y_0$ and $\hat y_a$ denote the zero-shot and adapted predictions. Define
\begin{align}
\mathrm{help} &= \Pr(\hat y_0\ne y,\ \hat y_a=y),\\
\mathrm{harm} &= \Pr(\hat y_0=y,\ \hat y_a\ne y).
\end{align}
Then $\Delta\mathrm{accuracy}=\mathrm{help}-\mathrm{harm}$. Conditional harm divides the harm count by the number of correct zero-shot predictions; it has a different denominator from the harm rate.
